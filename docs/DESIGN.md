# 架构设计

## 使用场景

参考视频社区的浏览与互动方式：真实视频上传、分类搜索、播放、评论、弹幕、点赞和收藏。首版为单用户本地工作台。

## 首版结构

FastAPI承接上传与社区API；SQLite保存视频元数据、评论、弹幕和个人互动状态。媒体文件独立目录，播放器通过ID读取，不接受任意路径。UI为首页浏览、上传弹窗与播放详情三个视图；第一版没有多用户身份声明。

模块边界：`app/main.py` API与业务，`app/common.py` 本机访问保护/持久化/导入工具，`app/web/` 无构建前端，`tests/` 边界回归。

## 数据与访问

data/app.db 和 data/media/，用户视频、评论与收藏仅存本地。上传失败清除临时文件。

默认回环绑定并核验Host和写请求Origin；UI文本转义，静态内容CSP，上传使用生成ID。数据库事务不包含外部模型调用。此保护不替代多用户认证。

## 边界

- 仅绑定回环地址，尚无账户、生产权限或公网部署保障
- 没有FFmpeg转码；MP4/WebM容器校验不保证浏览器支持内部编码
- 单文件最高512MiB；评论与弹幕以本地用户身份保存
- 没有CDN、推荐算法、内容审核或版权内容；不复制B站素材和商标
