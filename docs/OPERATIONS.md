# 运行与恢复

使用README中的本机启动命令。访问 http://127.0.0.1:8766 。单进程运行，避免多个进程争抢本机后台队列。

## 数据备份

停止服务后备份整个APP_DATA_DIR（默认data/），包含app.db、媒体/处理资源和队列输入文件。运行时直接拷贝SQLite单文件可能丢失WAL事务，必须先停机或使用SQLite backup API。恢复时停机，将完整备份放入数据目录再启动。书库/知识库的页面JSON备份只覆盖页面说明的内容，不包含账户密码、会话或原始媒体。

日志可由uvicorn输出收集；异常队列在页面显示失败原因并可重试。监控 /openapi.json 和进程存活，不把上传数据发到外部监控。

## 本机部署

无需外部数据库、CDN或云账号。三个Web项目可使用仓库Dockerfile和compose.yaml；端口只发布在127.0.0.1，容器内使用0.0.0.0以接收宿主转发。不要把本机访客模式直接发布公网。Docker配置仅静态检查，本机未安装Docker运行时。

公网服务需要独立设计TLS、可信反向代理、Secure Cookie、禁用访客、注册和上传限流、平台审核、存储配额与备份恢复演练。当前账户用于本机内容隔离，不代表上述生产条件已完成。
